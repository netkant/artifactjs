Quick Start

Three lines to shared state

Define an artifact outside your component. Use it inside. That's it.

import { artifact, useArtifact } from '@urlund/artifactjs';

// 1. Define shared state (outside any component)
const counterArtifact = artifact(0);

// 2. Use it anywhere
function Counter() {
    const [count, setCount, resetValue] = useArtifact(counterArtifact);

    return (
        <>
            <button onClick={() => setCount(count + 1)}>
                Count: {count}
            </button>
            <button onClick={resetValue}>Reset</button>
        </>
    );
}

Every component that reads counterArtifact shares one value. When any of them updates it, the rest re-render automatically. No providers, no context, no wiring.

Concepts

What can you put in an artifact?

Anything. A string, a number, an object, an array, a Promise, or a function that computes a value. Artifact figures out the rest.

Strings & Numbers

artifact("Hello")
artifact(42)

Objects & Arrays

artifact({ theme: "dark" })
artifact(["a", "b"])

Async / Fetch

artifact(() => fetch(url))
Suspends until resolved

Direct Promises

artifact(fetch(url))
Fetches immediately on load

Parameterized

artifact(({ id }) => ...)
One cache per unique params

Derived

artifact(({ get }) => ...)
Recomputes when deps change

maxAge / revalidate

artifact(init, { maxAge })
Expire cache on-read or auto

Static values

The simplest artifact holds a value. It works like a global useState that every component can access.

const nameArtifact     = artifact("Alice");
const settingsArtifact = artifact({ theme: "dark", lang: "en" });
const tagsArtifact     = artifact(["react", "typescript"]);

Reading & Writing

Use whichever hook fits your needs:

// Read + write + reset (like useState with reset)
const [theme, setTheme, resetValue] = useArtifact(settingsArtifact);

// Read and subscribe — this component re-renders on change
const theme = useArtifactValue(settingsArtifact);

// Set without subscribing — subscribed components still re-render
const setTheme = useSetArtifact(settingsArtifact);

// Reset to initial value
const resetTheme = useResetArtifact(settingsArtifact);

Calling useSetArtifact still notifies other components that use useArtifactValue or useArtifact.

The setter accepts a direct value or an updater function:

setTheme({ theme: "light", lang: "en" });
setTheme((current) => ({ ...current, theme: "light" }));
Async Data

Fetch data with Suspense

Pass a function that returns a Promise. The component suspends until the data arrives — no loading state to manage, no useEffect dance.

const usersArtifact = artifact(() =>
    fetch("/api/users").then((res) => res.json())
);

function UserList() {
    const users = useArtifactValue(usersArtifact);

    return users.map((u) => <div key={u.id}>{u.name}</div>);
}

// Wrap in Suspense for the loading fallback
<Suspense fallback={<div>Loading...</div>}>
    <UserList />
</Suspense>

Parameterized fetching

Need the same data shape for different IDs? Destructure the parameters. Each unique param set gets its own cache.

const userArtifact = artifact(({ id }) =>
    fetch(`/api/users/${id}`).then((res) => res.json())
);

function UserProfile({ userId }) {
    const user = useArtifactValue(userArtifact({ id: userId }));

    return <h1>{user.name}</h1>;
}

userArtifact({ id: 1 }) and userArtifact({ id: 2 }) are independent — updating one doesn't affect the other.

Resetting & re-fetching

Call useResetArtifact to re-run the initializer. For async artifacts, this means a fresh fetch with Suspense kicking in again.

const resetUsers = useResetArtifact(usersArtifact);

<button onClick={resetUsers}>Refresh</button>
Derived State

Artifacts that depend on other artifacts

Use get() inside an initializer to read another artifact. The derived artifact recomputes automatically when its dependency changes.

const todosArtifact = artifact(() =>
    fetch("/api/todos").then((res) => res.json())
);

const completedArtifact = artifact(({ get }) => {
    const todos = get(todosArtifact);
    return todos.filter((t) => t.completed);
});

const statsArtifact = artifact(({ get }) => {
    const todos = get(todosArtifact);
    const done  = get(completedArtifact);
    return { total: todos.length, done: done.length };
});

When todosArtifact updates, both completedArtifact and statsArtifact recompute. Only the components that read each one re-render.

Persistence

Persist state to storage

Use artifactWithStorage to create an artifact whose value is automatically persisted to localStorage or sessionStorage. It reads the stored value on creation, writes on every update, and syncs across browser tabs. The initial value is optional — when omitted (or the key is missing), the value is undefined.

import { artifactWithStorage, useArtifact } from '@urlund/artifactjs';

// Persists to localStorage by default
const themeArtifact = artifactWithStorage('theme', 'light');

// No default — missing key yields undefined
const tokenArtifact = artifactWithStorage<string | undefined>('CapacitorStorage.token');

function ThemeToggle() {
    const [theme, setTheme, resetValue] = useArtifact(themeArtifact);

    return (
        <>
            <button onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}>
                Theme: {theme}
            </button>
            <button onClick={resetValue}>Reset</button>
        </>
    );
}

The value persists across page reloads. If another tab updates the same key, this tab receives the change automatically via the browser's storage event. When using options without a default, pass undefined as the second argument: artifactWithStorage('token', undefined, { storage: () => sessionStorage }).

Session storage

Pass a storage option to use sessionStorage instead:

const draftArtifact = artifactWithStorage('draft', '', {
    storage: () => sessionStorage,
});

Custom serialization

Override serialize and deserialize for non-JSON-friendly types:

const tagsArtifact = artifactWithStorage('tags', new Set(), {
    serialize: (v) => JSON.stringify([...v]),
    deserialize: (v) => new Set(JSON.parse(v)),
});

Options

OptionDefaultDescription
storage() => localStorageA function returning the storage backend (localStorage, sessionStorage, or any Storage-compatible object).
serializeJSON.stringifyConverts the value to a string for storage.
deserializeJSON.parseConverts the stored string back to a value.
Migration

Coming from Jotai or Recoil?

Artifact has the same atomic model — define state outside components, subscribe inside — but with a simpler API, native Suspense via React 19+'s use(), and zero dependencies.

Side-by-side: Jotai vs Artifact

Basic state

Jotai 
import { atom, useAtom } from 'jotai';

const countAtom = atom(0);

const [count, setCount] = useAtom(countAtom);
Artifact 
import { artifact, useArtifact } from '@urlund/artifactjs';

const countArtifact = artifact(0);

const [count, setCount, resetValue] = useArtifact(countArtifact);

Async data

Jotai 
const usersAtom = atom(async () => {
    const res = await fetch('/api/users');
    return res.json();
});
// Requires <Suspense> wrapper
Artifact 
const usersArtifact = artifact(() =>
    fetch('/api/users').then(r => r.json())
);
// Same <Suspense> support, native use()

Derived / computed

Jotai 
const doubleAtom = atom(
    (get) => get(countAtom) * 2
);
Artifact 
const doubleArtifact = artifact(
    ({ get }) => get(countArtifact) * 2
);

Parameterized (family)

Jotai 
import { atomFamily } from 'jotai/utils';

const userAtom = atomFamily((id) =>
    atom(async () => { /* fetch */ })
);

useAtomValue(userAtom(123));
Artifact 
// Built in. No extra import.

const userArtifact = artifact(({ id }) =>
    fetch(`/api/users/${id}`).then(r => r.json())
);

useArtifactValue(userArtifact({ id: 123 }));

Reset / refresh

Jotai 
import { useSetAtom, RESET } from 'jotai/utils';

const reset = useSetAtom(myAtom);
reset(RESET);
// Only works with atomWithReset
Artifact 
const reset = useResetArtifact(myArtifact);
reset();
// Works with every artifact. Re-fetches async.

// Built in. Cross-tab sync included.

Advanced

Using outside React

For tests, scripts, event handlers, or WebSocket callbacks — Artifact works without hooks too.

import { readArtifact, resolveArtifact, writeArtifact, resetArtifact, subscribeArtifact } from '@urlund/artifactjs';

// Read (sync peek — may be undefined while pending)
const value = readArtifact(counterArtifact);

// Wait until resolved (event handlers, scanners, non-React code)
const order = await resolveArtifact(orderState({ id: 42 }));

// Write
writeArtifact(counterArtifact, 42);

// Reset to initial (re-fetches if async)
resetArtifact(counterArtifact);

// Subscribe to changes
const unsubscribe = subscribeArtifact(counterArtifact, () => {
    console.log("Changed:", readArtifact(counterArtifact));
});

unsubscribe();
Error Handling

Errors propagate to Error Boundaries

If an initializer throws or a fetch rejects, the error surfaces at the nearest React Error Boundary. Combine with <Suspense> for a clean loading + error pattern.

import { ErrorBoundary } from '@/components/ErrorBoundary';

<ErrorBoundary>
    <Suspense fallback={<div>Loading...</div>}>
        <UserList />
    </Suspense>
</ErrorBoundary>

Full API

React hooks

ExportTypeDescription
useArtifact(ref)hookReturns [value, setValue, resetValue]. Subscribes to changes.
useArtifactValue(ref)hookReturns the current value. Subscribes in this component — re-renders when the artifact updates.
useSetArtifact(ref)hookReturns a setter without subscribing in this component. Subscribed components still re-render when the value changes.
useResetArtifact(ref)hookReturns a reset function. Restores initial value or re-fetches.

Outside React

ExportTypeDescription
artifact(init, opts?)functionCreate an artifact from a value, promise, or function. Optional maxAge / revalidate control cache freshness.
artifactWithStorage(key, init?, opts?)functionCreate an artifact persisted to localStorage or sessionStorage with cross-tab sync. Initial value is optional (defaults to undefined).
readArtifact(ref)functionRead the current value synchronously (sync peek).
resolveArtifact(ref)functionWait until resolved; returns a Promise. Rejects on artifact error.
writeArtifact(ref, v)functionWrite a new value. Notifies all subscribers.
resetArtifact(ref)functionReset to initial value. Re-runs initializer if function/promise.
subscribeArtifact(ref, fn)functionListen for changes. Returns an unsubscribe function.
